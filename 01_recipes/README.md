# 01_recipes/

## Purpose

This directory contains recipe frameworks, prep manuals, nutritional guidelines, timing standards, and component matrices for PureDrive-style organic fast food.

**Important**: Full proprietary recipes are living documents. Early releases focus on principles, component systems, and scalable methods so local operators can adapt while maintaining integrity and speed.

## Structure (planned)

- `components/` — Shared bases (grains, greens, proteins, sauces, dressings)
- `bowls/` — Standard bowl builds with assembly sequences
- `handhelds/` — Wraps and sandwiches
- `beverages/` — High-margin drinks and functional options
- `prep_timings/` — Sous-vide, batch cooking, and holding standards
- `nutrition/` — Macro matrices and allergen matrices
- `local_adaptations/` — Community-submitted regional variations

## Contribution Guidelines

- All recipes must use only certified organic ingredients (or clearly note allowed exceptions).
- Prioritize shared components across the menu.
- Include yield, portion size, holding time, and critical control points.
- Submit improvements via pull request with clear before/after impact (time, yield, taste, cost).

## Core Philosophy

Constraint > variety.  
Taste > purity theater.  
Speed + integrity = the product.

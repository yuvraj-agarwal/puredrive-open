# 06_financials/

## Purpose

Dynamic unit-economic models, templates, and guidance for operators and the core foundation.

## Planned Contents

- Google Sheets / Excel templates for weekly P&L tracking
- Spoke-level and hub-allocated cost models
- Sensitivity analysis tools (protein mix, AOV, volume, waste)
- Startup capital estimators for micro-stores
- Scenario planning for different markets (US, India, etc.)

## Philosophy

Numbers must be honest. Organic premiums are real. Model the downside as carefully as the upside. Update models with actual operating data as soon as it exists.

## Contribution

Share improved templates or anonymized real-world unit economics (with permission) so the whole network can learn.
